# Как проверить коллекции в Firebase Firestore

## Используемые коллекции в приложении

В приложении используются следующие коллекции:

1. **`catches`** - уловы пользователей
2. **`fishingSpots`** - места для рыбалки
3. **`userSettings`** - настройки пользователей
4. **`userProfiles`** - профили пользователей

## Как проверить коллекции в Firebase Console

### Шаг 1: Откройте Firebase Console
1. Перейдите на https://console.firebase.google.com/
2. Выберите ваш проект (rybachok-e4844)

### Шаг 2: Откройте Firestore Database
1. В левом меню нажмите на "Firestore Database"
2. Откроется список всех коллекций

### Шаг 3: Проверьте наличие коллекций

Вы должны увидеть коллекции:
- `catches` (может быть пустой, если еще не сохраняли уловы)
- `fishingSpots` (может быть пустой)
- `userSettings` (должна содержать документы с ID = userId)
- `userProfiles` (должна содержать документы с ID = userId)

## Важно!

**Коллекции в Firestore создаются автоматически** при первом добавлении документа. Вам НЕ нужно создавать их вручную!

Если коллекция `catches` отсутствует, это нормально - она создастся при первом успешном сохранении улова.

## Если коллекция не создается

Если коллекция не создается при попытке сохранения, проблема скорее всего в:

1. **Правилах безопасности** - они блокируют создание документа
2. **Авторизации** - пользователь не авторизован
3. **Структуре данных** - данные не соответствуют правилам

## Как проверить, что данные отправляются правильно

1. Откройте консоль браузера (F12)
2. Попробуйте сохранить улов
3. Проверьте логи - там должно быть:
   ```
   === ДОБАВЛЕНИЕ УЛОВА В FIREBASE ===
   Текущий пользователь: {...}
   Переданный userId: ...
   Данные для сохранения: {...}
   ```

## Как создать тестовый документ вручную (для проверки)

Если хотите проверить, что правила работают:

1. В Firebase Console → Firestore Database
2. Нажмите "Start collection"
3. Collection ID: `catches`
4. Document ID: (оставьте пустым для автогенерации)
5. Добавьте поля:
   - `userId` (string): ваш userId (например, `VLYCnO45hoV8V7MTs3kB3Qh0mR43`)
   - `fishType` (string): "Тест"
   - `weight` (string): "1"
   - `date` (timestamp): текущая дата
   - `createdAt` (timestamp): текущая дата

Если это не работает из-за правил, значит проблема в правилах безопасности.
